# Feature Banks

This directory stores the EasyLens shape banks required by the official subtle-lesion MedGemma1.5 evaluation runner.

The banks are copied from the original bank/train-split construction outputs used by the result tables. They are not built from the held-out test benchmark directories.

See `banks/subtle_lesion_medgemma15/MANIFEST.json` for source paths, expected sizes, and SHA-256 checksums.
